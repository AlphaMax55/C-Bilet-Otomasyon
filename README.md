C# Bilet Satın Alma Otomasyonu (Bus Ticket Automation System)
Bu proje, C# programlama dili ve Windows Forms kullanılarak geliştirilmiş; kullanıcıların sefer sorgulama, koltuk seçimi ve güvenli bilet rezervasyonu / satın alma işlemlerini gerçekleştirebildiği, kapsamlı bir otomasyon sistemidir.

🚀 Kurulum ve Çalıştırma Adımları (Installation)
Projeyi yerel bilgisayarınızda (Visual Studio ortamında) çalıştırmak için aşağıdaki adımları sırasıyla takip edebilirsiniz:

Projeyi Klonlayın veya İndirin:

Depoyu bilgisayarınıza indirin veya klonlayın.

C-Bilet-Otomasyon.sln dosyasını Visual Studio ile açın.

Veritabanı Yapılandırması:

Projede MSSQL (veya kullanılan veritabanı altyapısı) kullanılıyorsa, ilgili veritabanı dosyasını SQL Server'a ekleyin.

App.config veya bağlantı cümleciği (connectionString) barındıran dosya içerisinden kendi sunucu/veritabanı bilgilerinizi güncelleyin.

Projeyi Derleyin ve Çalıştırın:

Visual Studio üst menüsünden Build > Build Solution seçeneği ile projeyi derleyin.

F5 tuşuna basarak veya Start butonuna tıklayarak uygulamayı ayağa kaldırın.

🛠️ Kullanılan Teknolojiler ve Mimari
Dil: C#

Arayüz: Windows Forms

Veritabanı Yönetimi: ADO.NET / MSSQL

Mimari: Katmanlı / Modüler Yapı

📌 Temel Özellikler
Sefer Yönetimi: Güzergah, tarih ve saat bazlı otobüs seferlerini listeleme.

Dinamik Koltuk Seçimi: Otobüs oturma planı üzerinden boş/dolu koltuk kontrolü ve koltuk rezerve etme.

Yolcu Bilgi Formu: Bilet alacak yolcunun kimlik ve iletişim bilgilerini sisteme kaydetme.

Yönetici Paneli: Sefer ekleme, silme ve bilet satış raporlarını görüntüleme.
